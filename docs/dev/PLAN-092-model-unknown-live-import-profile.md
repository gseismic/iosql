3. 在独立临时库回放真实 CSV，以计时包装统计原始写入、连接创建/关闭、commit 和 SQL 执行；cProfile 用于定位 Python 热点，墙钟计时与 profiler 的扰动分开说明。
4. 优先使用 NVMe 副本；必要时只用少量独立临时文件测 M3 的连接/写入成本，不向正式数据库或业务 manifest 写入，不调整同步级别。
