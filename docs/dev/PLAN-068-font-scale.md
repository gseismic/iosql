# PLAN-068: Web 界面字体调大 + 字号缩放开关

- 日期：2026-09-28
- 反馈：用户在真实库界面上反馈"字体太小"。现状正文 13.5px、表格 12px、
  次级标注 11px，对数据密度工具偏小。

## 实施项

| # | 项 | 内容 |
| --- | --- | --- |
| P1 | 默认字号整体上调一档 | 全站字号映射 +1px（15→16、14→15、13.5→14.5、13→14、12.5→13.5、12→13、11.5→12.5、11→12、10.5→11、10→10.5、9.5→10）；大数字（20/24/26px）与图标字号不动；仅 `font-size:`/`fontSize:` 属性，间距不动 |
| P2 | 字号缩放开关 | 底部状态栏新增 `A− / 标准 / A+` 三档（body zoom 1 / 1.1 / 1.2），localStorage `iosql_web_font_scale` 持久化，boot 时应用 |
| P3 | 布局随动 | .col-picker 宽度 320 → 340px 适配更大字号 |

## 不做

- 全站 px → rem 体系重构（收益低、churn 大；zoom 方案已满足需求）
- 表格行高/密度单独开关

## 验收

1. `node --check` 全部 JS；`pytest tests/test_web.py tests/test_plan062_web.py tests/test_cli.py` 通过。
2. 真实库浏览器截图：默认档明显大于改前；A+ 档可用且不破版（顶栏/侧滑/弹窗正常）。
