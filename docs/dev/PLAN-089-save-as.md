## 验收标准

- `Database.save_as()` 与三个 engine 的 `Table.save_as()` 使用一致的规范参数；
  返回已有迁移结果类型，保持 `migrate_to()` 的默认值与行为。
- 成功另存后源库仍可重开查询，源对象 URI 不变，源目标后续写入互不影响。
- 新入口完整复用迁移发布和锁机制，不发生外层共享租约升级失败；失败不发布部分目标。
- 用户可按示例保留两份相同数据，并采用相同查询及消费方式进行计时。
- 文档、示例和仓库内 skill 副本一致，结果文件准确记录验证范围。
