## 场景与边界

图表适用于行情、传感器、业务指标和分类数据。用户选择筛选条件、X 列、Y 列，以及可选的分组列；组内每一行保留为独立原始观测。时间 X 与数值 Y 使用折线；其他数值或文本组合使用散点，文本以明确的类别刻度显示。时间按契约识别，普通文本不猜测时区。OHLC 四线作为已有的可选图型保留。

未筛选时允许用户明确点击绘制全部；初次进入不自动发起全表图表请求。已有 `symbol_column` 契约仅作为初始分组字段的候选，界面不要求或写死该名称；没有该契约的表默认不分组。分组超过 32 个时显式失败并提示添加筛选，不能静默选择或丢弃数据。X 为空值或类型与契约不符时显式失败；Y 空值仍作为断点或不显示的点，保留在计数中。

超过 JavaScript 安全整数范围的整数坐标不能精确绘制，接口明确报错；大整数分组以十进制文本传输，避免相邻分组被合并。条件输入保留超出安全范围的整数文本，避免浏览器在提交前舍入。

## 接口方案与兼容性

保留现有 `GET /api/table/{name}/chart` 的参数、NDJSON 事件与金融分线行为，避免破坏既有调用。新增只读 `POST /api/table/{name}/chart`，以 JSON 提交 `x`、`y`、可选 `group_by`、`where` 和图型；其中 `where` 复用现有 Data 端点的条件数组及 AND/OR 语义。返回 NDJSON 的 meta/data/done/error 事件，使用通用 `group` 标识分组，提供坐标类型、总记录数与每组计数。未知列、非法条件和不支持的列类型在读取前返回可理解的错误。

比较过在 GET 查询字符串中编码复杂条件和新增只读 POST：后者避免嵌套筛选序列化为不受控的长 URL，并使轴、分组与筛选有明确契约；GET 原接口保持兼容。筛选、列投影、排序继续下推底层读取器，不新增读取全部数据来发现分组的预查询。

2026-11-06 01:06 补充：真实 PostgreSQL 测试确认重新打开普通表时 `spec()` 可能为 `None`。此时读取物理列类型作为轴选择依据，不虚构时间或分组契约；`GET /spec` 保留 `spec: null`，仅附加可选的物理 `columns` 字段供前端使用。已有契约仍优先，避免改变旧调用方对契约存在性的判断。

2026-11-06 01:13 补充：`date` 类型或明确的 `time.unit=date` 是日历日期，不应仅因文本存储而当作普通类别。接口保留原始日期值；前端将合法的 `YYYY-MM-DD` / `YYYYMMDD` 映射为日历轴并以 UTC 日历刻度显示，不将日期解释为本地瞬间。日期 X 的缩放使用已加载数据，避免把毫秒坐标错误地传给日期列；非法日期显式报错。

## 浏览器与图表引擎

参考 `mchart3.js/examples/010_base_chart.html`、`317_phase_data-mapping.html` 和 `705_stats_categorical.html`，使用框架无关的 Canvas 二维引擎。将指定版本的必要模块打包随 iosql 分发，不依赖 sibling 工作目录或网络。折线明确设置 `downsample: false`，保留全部原始点、空值断线和重复 X；分类值使用可追溯的刻度映射，不对观测做聚合。缩放时对数值或时间 X 保留按可视窗口重查的行为，条件和分组沿用实际绘制时的快照；分类轴缩放基于当前已载入的数据。

2026-11-06 01:22 补充：图表引擎在第一次绘制时加载，其他工作区不下载该资源；加载失败时允许重新点击绘制重试。切换工作区或发起新绘制后，旧的加载完成不能触发过期查询。

图表销毁或切换时取消请求并释放 Canvas 实例；输入未提交时不改变已绘制图表的缩放查询。样式沿用既有深色工具界面，筛选构造器复用 Data 的现有组件。

## 风险与复核

全量原始点对浏览器 CPU 和内存仍有成本，因此不自动触发查询，用户可以通过任意列及时间条件缩小范围。空值、类别编码、重复 X、分组上限和晚到响应均须自动测试；对不能可靠表达的数据类型明确报错，不将其伪装成正确图表。实施前复核：兼容 GET、保留 OHLC、避免隐式跨组连接、跨后端复用公共查询接口、避免浏览器重新请求使用尚未提交的输入。
