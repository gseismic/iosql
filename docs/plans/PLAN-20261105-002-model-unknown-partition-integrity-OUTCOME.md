## 遗留与限制

- SQLite/Parquet 不会自动把任意原始写入值转换为 UTC；表示绝对时刻的数据应由调用方按契约传入 UTC 秒或毫秒。原始行未自动改写；旧错误时间契约或旧纯日期路由需要按 README 指引显式复制迁移。
- PostgreSQL 旧表首次写入固定分区摘要需要表所有者权限。对于不兼容旧布局和已有重复主键，不自动删除、合并或移动业务数据。
- PostgreSQL 写入逐次检查现有子分区，随分区数增长存在开销；待评估优化见 `TD-20261105-1817-001`（`docs/todos/TD-20261105-1817-001-pg-partition-validation-performance.md`）。
