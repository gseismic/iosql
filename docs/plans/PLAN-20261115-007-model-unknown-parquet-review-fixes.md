## 实施前自查、风险与回滚

已自查：统一清单解析要保留原文件名校验与防越界约束；仅替换引擎主扫描不足，需覆盖查重、修改、迁移计数及身份校验。NaN 必须在排序键和业务值两处保留，不能只修返回次序；多列 NaN 相等时需继续比较后续键。compact 使用磁盘暂存，不引入全表内存物化。零新增批次仍可能新增契约列，不可提前跳过元数据。父目录同步失败须发生在提交决定之前。

主要风险是最低 DuckDB API 差异、排序暂存的资源清理及失败隔离、清单解析变动对迁移完整性判断的影响。以隔离临时库和故障注入验证；失败保留旧可见文件和恢复屏障。回滚仅撤销本次改动，不改写既有业务库或用户文件；正常验证不访问用户业务数据。
