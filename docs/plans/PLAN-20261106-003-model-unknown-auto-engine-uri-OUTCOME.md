## 完成情况

- 已有 SQLite/Parquet 目录库支持按普通路径及 `iosql:///` 自动识别；旧后端前缀继续可用，新增 `iosql+` 前缀。新库及新迁移目标通过显式前缀或引擎参数确定类型。
- 库级标记固定存储类型，旧库只读识别表级元数据；错误前缀、混合类型或无法识别的库拒绝访问。初始化、表构造、写入和扫描使用跨进程锁协调；SQLite 快照与代际、Parquet 平坦发布及恢复保留身份。
- CLI Web 使用自动识别的后端，Parquet 表可浏览和使用 Charts 绘图；不支持 Parquet 的 SQLite 维护命令明确拒绝。使用文档及相关回归已更新。

## 计划偏差与自查

识别和写入并发时可能观察到尚未提交的表元数据，因此增加共享/独占类型锁；不同表的写入仍可并行。为保持路径精确，内部 URI 对问号及边缘空白路径编码，并覆盖百分号、尾随空格、相对路径和 fork 子进程持锁的情况。具体取舍见 `docs/design/local-uri-engine-20261106-overview.md`。

- 用户原有 Web 进程仍在运行，需在原终端停止并重启才能加载此次修复；本次未终止该进程。
