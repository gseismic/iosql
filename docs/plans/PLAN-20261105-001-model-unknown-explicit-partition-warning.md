## 风险、回滚及实施前自查

- Python 调用绑定后无法区分显式 `1day` 与默认 `1day`。采用 `functools.wraps` 保留公开签名的包装，在原始关键字参数上判断，避免误报和默认值变更。
- 即使两者等价，显式 `partition_every` 也确实未参与选择；提示这一事实，不改成拒绝调用。用户可通过 Python warnings 机制管理警告。
- 警告应先于建表和绑定；当调用方把警告升级为异常时，不应产生这些副作用。公共入口的协调包装可能影响 `stacklevel`，必须用测试验证。
