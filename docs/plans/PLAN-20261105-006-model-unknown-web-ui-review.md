## 目标、范围与约束

审查并优化 iosql Web 的高频浏览和诊断体验：修复已复现的界面与数据表达错误，改善状态恢复、可访问性、视觉层级和窄屏布局。沿用零构建链、既有五工作区和主题，不改变数据库 API、图表数据语义、写入权限或危险操作确认。非 Web 功能和与当前审查无关的重构不在范围内。

## 当前状态与依据

独立示例库和 Chromium 实测：切换 Structure/Charts 后返回 Data，表格 DOM 消失；对象式内联样式未生效，Structure 分区条比例有误；移动宽度侧栏挤占工作区。代码另显示快捷翻页作用域、统计失败状态及重试、分区过滤上界、键盘访问和颜色对比存在问题。范围涉及 `iosql/web/static/` 及与行为相关的测试；计划、设计和结果文档按项目规范保存。

## 实施步骤

1. 修复通用 DOM 样式设置、Data 重入和请求状态、快捷翻页、空/错误恢复；为表头及导航补充可访问状态。
2. 修正总览统计进行中、部分失败及重试的表达，避免错误健康结论和分布节点嵌套；安全展示有依据的时间范围，提供重新加载及现有行数缓存提示。Data 的刷新同步重新计数。
3. 修复 Structure 的分区比例及可精确推导的分区跳转边界；对不能安全推导的情况不提供误导性跳转，大量分区按需追加显示。
4. 保留既有 IA 优化文字对比、卡片、可见焦点和主要布局；增加窄屏侧栏抽屉、工作区导航与表格适配；只读维护页说明开启方式。
5. 自查、浏览器验证并运行相关自动化回归，记录结果与遗留问题。

2026-11-05 20:44 复核补充：切离 Charts 时，在途原始点流可能继续读取大量数据；切离 Data 时未完成的分页请求也应停止。增加工作区卸载清理，验证取消信号和重新进入行为，不改变图表数据或后端接口。

2026-11-05 20:51 时间输入复核补充：浏览器原生解析会将纯日期视作 UTC、无时区日期时间视作本地时间，且可能将无效日期滚动到下月。统一无时区的日期和日期时间按浏览器本地时间解析并显式提示；拒绝无效日历日期、夏令时跳变中不存在的本地时间和斜杠日期等非 ISO 格式，保留明确时区和毫秒时间戳的含义。验证同一时刻的两种输入、无效日期、显式时区及查询请求；这是前端输入行为变化，需在使用说明和结果中说明兼容影响。

## 验证和完成标准

- 自动化覆盖表格离开再返回、快捷分页、样式比例、分区边界、统计失败及重试等真实风险；测试通过并检查 JS 语法。
- 真实浏览器在桌面及窄屏检查 Overview / Data / Structure / Charts / Maintain，覆盖正常、空、加载、失败、长内容、键盘导航和只读/可写入口；验证筛选、分页、详情、图表、分区跳转及维护确认未回归。
- 运行 `tests/test_web.py` 和 `tests/test_plan062_web.py` 等相关测试；必要时扩大范围。对无法验证的环境或行为如实记录。

## 风险与回滚

DOM 样式修复会影响多个页面，需逐页检查；前端统计与请求异步更新要防止旧响应覆盖新状态；分区跳转只对能确认字段及区间的分区启用；CSS 缩放和小屏布局需检查表格及弹窗不被遮挡。变更仅涉及可逆的前端和文档；回滚时按本次文件差异撤销，不覆盖用户其他改动。

## 实施前自查

已复核设计：沿用先前确认的 IA，不引入额外导航；统计值与颜色不会暗示未经验证的数据健康；不以分区键范围冒充真实数据范围；分区跳转必须排除上界且验证分区字段；不会绕开只读服务端隔离。具体实现和测试若暴露新的实质范围变化，先更新本计划。
